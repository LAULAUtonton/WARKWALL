# WORKWALL

## Training 2 — free speaking practice

Independent preview at `training-2/index.html`. Students choose host or guest and practise A1–A2 questions about personal information and work.

- Browser speech synthesis and speech recognition; Chrome/Edge and HTTPS recommended.
- Progress checks recognised words, not precise pronunciation.
- Guided virtual partner, without generative AI or paid API keys.
- Indicative practice score, downloadable report and prepared email; students must send the email themselves.
- Teacher transcript testing yields TEST, not an oral score.
- Students use fictional character details. Browser speech recognition may send audio to its own recognition service.

## Publication
